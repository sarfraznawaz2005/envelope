# Envelope — app

This is the client half of Envelope. See the [root README](../README.md) for
what this project is and how to install and run the whole thing (this app
plus the relay).

Quick reference for developers already set up:

```bash
pnpm install
pnpm dev         # dev server with hot reload
pnpm typecheck   # vue-tsc, no emit
pnpm test        # vitest
pnpm build       # production build -> dist/
pnpm preview     # serve that build locally
```
